# 每日皇冠幣測驗答題擴展插件

自動作答 Wizard101 每日 10 份皇冠幣測驗的 Chrome 擴充功能 (Manifest V3)。
自動登入、依序作答、跑完自動排下一次，需要手動處理的只剩每份測驗結束時的 CAPTCHA 驗證。

本專案以既有的 DCQAE 擴充功能為基礎修改而來，原作者已不可考，原本的說明保留在文件最下方的[原作者 README](#原作者-readme)。

## 功能

- **自動作答**：依序開啟 10 份測驗，比對內建題庫自動選答案。也可以改成只標示答案，由你自己點選。
- **自動登入**：在選項頁填入帳號密碼後，未登入時會自動登入。
- **定時自動開始**：從皇冠幣紀錄頁讀出下次更新時間，時間到時自動開新分頁開始作答，跑完再排下一次，每天循環。
- **驗證提醒**：需要完成 CAPTCHA 時：
  - 播放音效
  - 顯示系統通知，點擊即切換到測驗分頁
  - 自動切換到測驗分頁
  - 分頁標題閃爍「⚠ 需要驗證」
- **圖示徽章**：進行中顯示藍色「3/10」，等待驗證顯示紅色「!」，完成顯示綠色「✓」。
- **完成摘要通知**：跑完後通知本次獲得的皇冠幣與下次自動開始時間。
- **彈出面板**：點擴充圖示可查看狀態、本次獲得、下次自動開始、累計皇冠幣，並可開始、前往驗證或開啟選項。
- **皇冠幣紀錄頁**：標示 20 小時內的入帳紀錄，並提示下次更新時間。

## 安裝

1. 下載或 clone 這個 repository。
2. 在 Chrome 開啟 `chrome://extensions`，打開右上角的「開發人員模式」。
3. 按「載入未封裝項目」，選擇 repository 的資料夾。
4. 安裝後會自動開啟選項頁。

更新程式碼後，要回到 `chrome://extensions`，在擴充功能上按重新整理 ↻ 才會生效。

## 使用方式

### 第一次設定

在選項頁 (點擴充圖示 → **選項**) 設定：

- **自動登入**：Wizard101 帳號與密碼。
- **自動排程**：
  - 自動開始：在測驗重置時自動開始 (預設關閉)
  - 系統通知：需要驗證時顯示通知 (預設開啟)
  - 自動切換分頁：需要驗證時切換到測驗分頁 (預設開啟)
- **聲音**：測驗結束時的提示音。
- **答案選擇**：自動選擇或只標示答案、標示顏色、作答前等待秒數。

### 手動開始

點擴充圖示 → **開始**。之後每份測驗結束時完成 CAPTCHA，其餘都會自動進行。

### 定時自動開始

1. 在選項頁勾選「自動開始」並按 **保存**。
2. 擴充功能會在背景讀取皇冠幣紀錄頁，選項頁會顯示「下次自動開始時間」。
   如果顯示「目前測驗已可作答」，代表現在就能作答，手動跑完一輪後就會自動排程。
3. 時間到時會自動開新分頁開始作答，跑完後排下一次。

到時間時 Chrome 必須是開著的。

## 注意事項

- **CAPTCHA 需要手動完成**，這是網站確認真人操作的關卡，本擴充功能不會繞過它。
- **通知沒有出現**時，請檢查作業系統是否允許 Google Chrome 顯示通知，以及是否開啟了勿擾/專注模式。分頁標題閃爍與自動切換分頁不受系統通知設定影響。
- **密碼以明文儲存**在 `chrome.storage.sync`，會隨 Google 帳號同步。若有疑慮，請留空並保持瀏覽器的登入狀態。
- **累計皇冠幣是估計值**：每完成一份測驗加 10，實際入帳請以皇冠幣紀錄頁為準。
- 自動作答可能違反 KingsIsle 的服務條款，請自行評估帳號風險。
